# Sicherheitsrichtlinie

## Unterstützte Version

Sicherheitskorrekturen werden für die aktuelle Version beziehungsweise den
aktuellen Entwicklungsstand auf `master` geprüft. Für ältere Versionen gibt
es derzeit keine garantierte Sicherheitswartung; aktualisiere nach Möglichkeit
auf die aktuelle Veröffentlichung.

## Sicherheitslücke vertraulich melden

Bitte veröffentliche keine ausnutzbaren Details in einem Issue, Pull Request
oder einer Diskussion. Verwende auf GitHub die Funktion **Report a
vulnerability** auf der
[Sicherheitsseite dieses Repositorys](https://github.com/heddes-python-dev/pyti_lernumgebung/security).
Die vertrauliche Meldung ist für dieses Repository aktiviert.

Nenne in der Meldung nach Möglichkeit die betroffene Version, die
Voraussetzungen, den beobachteten Effekt und eine sichere Möglichkeit zur
Reproduktion. Sende keine Zugangsdaten, personenbezogenen Daten oder fremden
Geheimnisse. Wenn die vertrauliche GitHub-Meldung vorübergehend nicht
verfügbar ist, kontaktiere den Repository-Maintainer
[@heddes-python-dev](https://github.com/heddes-python-dev) privat über GitHub
und veröffentliche die Details nicht öffentlich.

Der Maintainer koordiniert Prüfung, Rückmeldung und Behebung. Eine
unabhängige Sicherheitsbewertung der Skriptisolation ist weiterhin offen;
die Meldung einer Schwachstelle oder ein erfolgreicher CI-Lauf ist keine
Sicherheitsfreigabe für fremde Skripte.
